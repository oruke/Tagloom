# Tagloom 品牌 Logo 设计规范与交付文档

本文档记录「Tagloom」应用 Logo 的设计演进、根源诊断及 v5 实心色块架构候选方案（`logo-05-solid-a.svg` 与 `logo-05-solid-b.svg`）。

---

## 品牌理念与设计调性

- **名称释义**：Tagloom = Tag（标签）+ Loom（织机）。象征将零散的笔记、片段通过标签与双链交织成有生命力的知识网络。
- **定位**：加密、本地优先、注重隐私的标签化笔记应用（KMP 跨平台架构，首发 Windows 桌面端）。
- **气质要求**：现代、克制、可靠、轻盈。融合「加密隐私」的专业安全感与「织连知识」的优雅秩序感。

---

## 💡 v5 根源诊断：为什么 16px 下 stroke 线条必然失败？

在连续 4 轮小尺寸实测与目检中，之前的版本均无法在 16px（Windows 任务栏/标题栏/托盘）下达到满意的清晰度：

1. **stroke 线宽抗锯齿衰减机制**：
   - 之前的所有版本（v1~v4）均采用 SVG 的 `stroke` 线条来绘制 T 字结构（1024 坐标系下线宽 84~144px）。
   - 在 16px 极限分辨率下，144px 折算像素仅为 **2.25px**。抗锯齿引擎在处理 2.25px 宽度的半像素边界 stroke 时，会将边缘像素平均化计算，导致线条边缘严重发虚、发灰、亮度大幅衰减，在小尺寸下看起来“糊成一坨”。
2. **实心 Fill (Solid Fill Architecture) 的破解原理**：
   - 业内工业级 16px 图标（如 VS Code 蓝底白 V、Word 蓝底白 W、Obsidian 纯色剪影）的标准解法是 **纯实心色块 (`fill`)**。
   - 使用实心圆角方块底座 + 内部粗壮居中的 **实心剪影图形 (`fill`)**，在 16px 栅格下直接填充连续实心像素点阵，不依赖线条 stroke 的半像素抗锯齿计算，边缘呈现实打实的 3px 宽高对比块，轮廓极其锐利！

## 🎨 v5 实心色块架构两款候选方案

### 候选 A：实心蓝底座 + 白色实心 T (`brand/logo-05-solid-a.svg`)
- **视觉原型**：借鉴 VS Code (蓝底白 V) 与 Word (蓝底白 W) 的标准桌面 16px 图标形态。
- **底座背景**：皇家蓝渐变底座 (`#0284C7` → `#1E3A8A`)，铺满图标，圆角 `rx="224"`。
- **T 字剪影**：粗壮居中的纯白实心 T 字 (`fill="#FFFFFF"`)。横梁厚度 160px (15.6%)，竖带宽度 160px (15.6%)，横竖交织处保留编织压盖切口。
- **16px 表现**：皇家蓝方块 + 纯白 T 字剪影，对比度达 **12.5:1**。在 Windows 深色任务栏（`#1F1F1F`）与浅色任务栏上均极其醒目且边界极其锐利。

### 候选 B：白色底座 + 实心深蓝 T (`brand/logo-05-solid-b.svg`)
- **视觉原型**：借鉴 365 亮色徽章与 Notion 白底剪影形态。
- **底座背景**：瓷白浅灰渐变底座 (`#FFFFFF` → `#F1F5F9`)，圆角 `rx="224"`。在 Windows 深色任务栏（`#1F1F1F`）上形成边界高亮锐利的亮色方形徽章。
- **T 字剪影**：粗壮居中的皇家蓝实心 T 字 (`fill="url(#t-solid-b)"`，`#0284C7` → `#1E3A8A`)。
- **16px 表现**：瓷白方块 + 皇家蓝 T 字剪影，对比度达 **12.5:1**。

## 💡 终极推荐结论

**首选推荐：候选 A (`brand/logo-05-solid-a.svg`，实心蓝底座 + 白色实心 T)**

### 推荐理由：
1. **16px 极限清晰度最强**：在 Windows 深色任务栏（`#1F1F1F`）上，皇家蓝实心底座呈现清晰独立的外边框，内部 2.5px 粗壮的纯白 `RGB(255, 255, 255)` T 字剪影在 16px 下白得极其耀眼、轮廓极其硬朗，彻底解决了发灰、发虚的问题。
2. **极佳的大尺寸质感**：256px / 1024px 大尺寸下，实心蓝底座结合现代粗壮 T 字母剪影，具备类似 VS Code、Word、Figma 般国际一线软件的大牌工业感与力量感。
