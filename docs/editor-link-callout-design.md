## 提示块

用途是突出一段需要记住的正文。结构只有一个可更换图标与一段 RichText；不要求单独标题，不默认添加“信息／建议／注意”级别字段。

- 输入 `/提示` 或 `/callout` 创建；普通段落也能保留内容和样式转为提示，反向转换时完整保留正文。
- 点击正文直接编辑，支持现有粗体、斜体、链接、颜色与加注。需要强调开头时由用户加粗文字，不新增标题字段。
- 点击左侧图标打开锚定图标的小选择器，复用已有图标目录及搜索，不再引入一套图标来源。
- 默认中性浅底；颜色和背景沿用现有块菜单与语义色。更换图标或颜色是展示设置，不改变正文结构或强加提示等级；切换主题时保留所选语义背景，映射到对应深浅配色。
- Enter 在块内换行；Ctrl/Cmd+Enter 在下方继续普通正文。块边界的退格、转换和删除必须保留内容，不能吞掉相邻块。
- 宽、窄窗口均按正文宽度排布，短提示保持紧凑，长提示自然换行。正文选区、查找与输入组合态复用现有富文本能力。

提示继续使用独立 `CalloutBlockContent`，不恢复通用 Card。协议接入、富文本与 Markdown 等实现仍待设计确认后的实施。

本地历史交互原型用于评审，未纳入源码；其中网页获取、保存与示例数据不代表生产能力。
