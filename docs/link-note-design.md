# 链接笔记、快捷录入与级联分组设计

状态：已实现，Windows 原生主流程已验收；Android 主机测试和 Debug 构建通过，设备交互未验收。本版替代把网页数据保存在 `bookmark` Block 的方案。提示仍是独立 `callout` 设计，不恢复通用 Card。

## 对象与属性

提供“链接”笔记类型，继承内置 `Note`，复用 `TagDefinition`、类型继承和 Note 快照。新笔记的直接类型身份集合仍为 `{Note, 链接}`（序列化按现有规范排序），不新增快照对象类型。

| 专属属性 | 约束 | 初始值与展示 |
| --- | --- | --- |
| URL | 必填，单个 HTTP(S) 网址 | 提交时写入，可直接打开或编辑 |
| 分组 | 可空，支持级联的单选 | 默认无值，显示“未分组”，无需填写即可创建 |

标题写入 `Note.title`，网页描述复用继承的描述属性 `WorkspaceDefaults.DEFAULT_TEXT_PROPERTY_ID`，普通标签继续复用已有目录。域名从 URL 派生，不新增域名、状态、日期、抓取状态等用户属性。创建时间仍来自快照头。

“链接”作为预置的普通类型提供，不按名称识别。创建时确认稳定类型 ID、URL 和分组属性 ID；已有工作区经统一 schema 事务补齐，不静默改写同名自定义类型。首次使用先确认可复用的属性及类型目录，再以一个跨 Note 事务确认目标与来源；中断最多留下未使用目录，不留下半条引用或孤立链接笔记。新建选择器可以展示尚未落盘的预置入口。

## 快捷录入

1. 空段落输入 `/link` 或 `/链接`，原位出现网址输入并自动聚焦。Slash 菜单、六点手柄的插入入口同样可进入，不需要先选类型或填写标题。
2. 录入网址，按 Enter。无协议的完整域名可补全 `https://`，其他输入就地校验并保留草稿；只接受 HTTP(S)，不把相对路径、脚本或文件协议当作网页。
3. 分组默认 null。输入下方的“未分组 · 可选”打开级联选择，忽略它也能提交。Esc 退出并恢复原段落，不留下空笔记或半个引用；输入法组合态 Enter 不提交。
4. 新链接以完整网址作为初始标题，创建链接笔记并插入笔记引用。两次写入经同一事务确认；原笔记 expectedRevision 过期时保留草稿并提示重试，不产生孤立对象。连续 Enter 在提交期间只执行一次。
5. 确认后焦点落到下方正文，可立即继续写作；后台静默请求网址，取得标题和描述后更新链接笔记，各处引用读取同一份内容。失败保留网址标题、空描述和引用，直接使用原有输入区手动编辑。

新建笔记选择“链接”时直接聚焦 URL，有效 URL 确认前不留下空对象。链接集合的“添加链接”复用相同录入，只创建链接笔记。独立网址粘贴到空段落时可选“保存为链接并引用”或“保留普通链接”，混合正文仍沿用现有粘贴规则。

### 重复与撤销

按规范化 URL 查找活动链接笔记：协议与主机名大小写、默认端口按 URL 标准归一；路径、查询参数和片段保留，不移除有意义参数，不按标题或重定向自动合并。

只有一个匹配时默认复用，直接插入已有引用，不重建、不改其分组或手动内容，反馈“已引用已有链接”。写入协调器内再次检查，防止并发创建。多个历史匹配时在原位列出已有标题供选择；本轮快捷入口始终复用选定目标，没有另设重复副本菜单。

撤销时，只有未继续编辑、未被其他笔记引用的刚建链接可与本次引用一起撤销；否则只移除本次引用。已撤销对象忽略旧请求回调，之后再次添加仍走同一创建与去重规则；跨对象操作没有单独接入编辑器的 redo 历史。

## 引用与详情

引用复用 `NoteReferenceBlockContent(noteId)`，增加“预览／行内”展示设置；不复制标题、描述、URL 或分组，不新增专门保存网页数据的 Block 协议。

- 预览显示域名、标题、最多两行描述和可选分组路径。没有图片时自然收紧，不制造空封面；首版不以图片下载为录入前置条件。
- 主体点击或 Enter 打开链接笔记；独立外链按钮打开网页。菜单、六点手柄、选择和拖动分别响应，不误触网页。
- 菜单提供打开笔记、打开网页、重新获取、切换行内和移除引用。移除只删除本次引用，不删除目标笔记；行内展示仍指向内部 Note，保留反链。
- 目标删除或不可用时保留稳定引用与解释，提供重选，不静默改为外部 URL；恢复删除目标仍属于工作区历史恢复流程。
- 详情复用标题、描述、身份行、属性和正文布局；按用户后续反馈移除整个附加页脚，不显示获取状态、失败说明、重试、刷新按钮或引用列表。

引用关系和反链索引仍从稳定引用派生，不维护双份关系；详情不再常驻显示反链列表。链接集合按“链接”类型查询为纵向列表，可搜索标题、URL 和描述，按分组筛选，点击进入同一笔记。

## 级联分组

### 共享属性能力

扩展现有 `select` 的可选层级模式，首版为单选提供级联；不新增 `cascade` 属性类型，不把分组建成笔记类型或普通标签的子类。

- `PropertyDefinition` 增加默认关闭的层级配置，`PropertyOption` 增加可空 `parentOptionId`，保持平铺的稳定 ID 目录。
- 值只保存一个选项 ID。`技术 → 前端 → CSS` 是按父链计算的展示路径，不存路径文字或祖先 ID 数组。
- 旧定义默认无父级、层级关闭，旧值不变。平铺模式保持全目录名称唯一；层级模式校验同级唯一，不同父级下可同名，搜索必须显示完整路径。
- 层级定义和自动字段来源使用快照 schema v2，并在同一提交中将 manifest 最低读取版本升级为 v2。当前读取器兼容 v1/v2，旧版 v1 客户端会拒绝打开已使用新能力的工作区，不能回写丢弃父链。普通旧工作区不因安装新版而自动升级，密钥轮换和备份恢复保留版本门禁。
- 父 ID 必须在同一目录，每项最多一个父级；校验自引用、循环和悬空父级，不硬编码三级。
- 分组绑定 `required=false`、`defaultPolicy=NONE`。UI/API 的 null 表示清空，在快照中移除显式值；“未分组”只是无值展示，不能成为字符串选项。核心校验与外部入口同步支持清空语义。

### 选择器

分组 chip 打开锚定选择器。桌面为单列可滚动层级树，窄窗口复用内容的底部面板，避免多列溢出。

- 顶部自动聚焦搜索，支持任一层名称和完整路径匹配；结果显示完整路径，区分同名项。
- 名称／单选标记选择本级，独立箭头展开或收起子级。父级和叶子均可选，点击名称确认关闭。
- 重新打开时自动展开当前值的祖先链，并滚动到选中项；搜索框仍获得焦点，不要求用户重新寻找原分组。
- 顶部“未分组”或已选值的清除动作均置为 null。
- 上下键移动焦点，左右键展开／返回，Enter 选择，Esc 关闭；焦点与选中分别反馈，触控扩大点击区域。
- 底部提供新建与管理。新建只需名称和父分组，先保存共享目录再应用到当前笔记或草稿；取消不改变选择。

### 维护与查询

维护复用属性定义的共享选项目录，笔记类型页提供入口；层级列表支持新增、重命名、移动父级和删除，不使用表格。改名或移动保留 ID，各处路径自动更新。父级选择排除自身和后代，禁止循环。

首版禁止直接删除有子项或被任意 Note 引用的选项，提示先移动子项／清理值并提供筛选入口；不得让已有值静默消失。未引用叶子经统一目录写入流程删除。

查询区分“是这个分组”和“属于此分组及下级”。集合选父分组默认包含本级和全部后代，并显示“包含下级”；精确筛选仍可选。“未分组”匹配无值，“全部分组”取消条件。当前集合按最新目录的后代 ID 集合过滤工作区已加载笔记，通用索引仍只保存实际 ID，不因改名或移动重写全部 Note；尚未为该集合额外增加 SQL 层级查询协议。

## 网页信息获取

有效网址回车已经发起该次请求，不再弹逐页授权。客户端仅请求指定 URL、受限重定向与元数据，不发送笔记正文、不带浏览器 Cookie、不通过密文同步服务器抓取；不抓全文、不执行网页脚本。网页内容只按数据解析。

标题依次取 `og:title`、HTML `title`；没有网页标题时保持初始网址标题或用户已编辑内容。描述取 `og:description`、`meta[name=description]`，缺失留空。压缩空白并限制长度。响应地址可解析相对资源，但不静默替换用户 URL、不按 canonical 声明合并记录。

| 状态 | 可观察行为 |
| --- | --- |
| 地址无效 | 原位解释、保留网址和分组，不创建 |
| 创建失败／revision 冲突 | 保留草稿，可重试，确认前不联网 |
| 已创建、正在获取 | 网址标题和空描述，不增加获取状态区域，正文继续编辑 |
| 成功 | 回填自动字段，各处引用更新 |
| 离线、超时或受限页面 | 保留网址标题、URL 和引用；未取得的描述为空，直接手动编辑，不显示失败提示和重试 |
| 缺少元数据 | 完整网址或已有手动标题，描述留空，不伪造信息 |
| URL 修改 | 取消旧请求、获取新地址，旧响应不能回填 |
| 锁定／切换工作区／删除目标 | 取消请求、释放会话数据，忽略晚到结果 |

首次回填只改自动且未被用户修改的标题／描述。等待期间或之后手动编辑过的字段，普通重试与刷新均保留；本轮没有强制替换手动字段的操作。来源状态随加密 Note 保存，重开后仍尊重手动编辑；抓取中／失败是运行时状态，不是可编辑属性。

每次请求绑定工作区会话、Note ID、规范化 URL 和请求版本。回填前读取最新 revision、按字段来源合并，再经 TransactionCoordinator 写入。重试不创建 Note、不插入第二个引用。

JVM/Desktop 和 Android 复用客户端 HTTP 适配：单次连接及读取超时 8 秒、最多 5 次重定向、只接受 HTTP(S) HTML 响应并最多读取 1 MiB 前缀；解析器扫描最多 1,048,576 个字符的页面头，避免大型内联样式或脚本将标题、描述挤出旧的 256 KiB 范围。解析仍止于 `</head>`，不执行脚本，支持响应 charset 和常见 HTML 实体。取消或锁定直接断开连接，不请求页面脚本、图片或正文归档。

## 协议与模块边界

```mermaid
flowchart LR
  E[编辑器 /link] --> S[创建链接与引用服务]
  S --> T[同一事务确认 Note 与来源引用]
  T --> F[可取消的客户端元数据端口]
  F --> U[校验 URL 和来源后事务回填]
  T --> I[派生类型与反链索引]
  U --> I
```

`core/commonMain` 承担类型约定、选项树和空值规则、URL 身份比较、元数据结果与合并规则；`app/shared` 承担录入、引用、选择器及页面状态；网络能力通过端口注入平台适配器，复用已有依赖。UI、CLI、MCP、Agent 写入走相同服务与事务。

Note 已增加版本化的可选 `linkMetadata` 来源记录，区分标题、继承描述的自动／手动来源及绑定 URL，不复制正文。旧 Note 缺省为手动内容，禁止误覆盖。来源记录、层级选项和引用展示设置位于加密快照中；普通 Markdown 的导出限制沿用已有有损能力说明，不将它视为完整工作区备份。

## 原型与原生实现

本地历史交互原型保留此前快捷录入、链接详情、级联分组、集合与失败场景的设计记录，未纳入源码；其获取和保存仍由页面内存模拟。当前生产实现使用原生 Compose、真实加密工作区和客户端 HTTP，独立于该原型。提示块设计见[原设计入口](editor-link-callout-design.md)。

Stitch 本轮修订稿请求再次超时，后续查询仍未取得 screen；本轮以本地交互原型和截图交付，不将项目存在作为生成成功。

原型经真实浏览器操作验证了 `/link` 原位进入、地址校验、网址回车、未分组默认值、重复复用、路径搜索、父级／叶子选择、后代／精确筛选、null 清空、分组改名移动关联、已用禁删、手动标题／描述保护、反链定位及失败重试。480px 窄窗口页面无横向溢出，选择面板宽 448px。桌面、窄窗口、深浅及失败截图作为本地历史评审材料保留，未纳入源码。

原生实现按职责分为 `core` 的选项树、URL 和字段来源策略，`app/shared/commonMain` 的录入与引用界面，以及 `jvmAndroidMain` 的统一事务和 HTTP 适配。没有新增第三方依赖；链接与来源 Note 的密文快照、Change 和 manifest 通过同一 `commitBatch` 确认。

原生主题、尺寸与公共组件边界见[原生界面记录](link-notes/DESIGN.md)。独立收尾评审将“长目录键盘游标可见”和“公共 Snackbar 配色”两项修正均判为 resolved，最终 disposition 为 ship，范围仅限这两项修正，未扩大到未验收的主题或设备状态。
